### Semester 1

###### OpenJDK 

Windows, macOS: [https://adoptium.net/temurin/releases](https://adoptium.net/temurin/releases)

```bash

# Distribution Build

# Ubuntu/Debian based

sudo apt install default-jdk

# Fedora or perhaps RHEL-based

sudo dnf install java-25-openjdk-devel

# Arch-based/Cachy/Endeavour 

sudo pacman -S jdk25-openjdk

# OpenSUSE

sudo zypper install java-25-openjdk

```
